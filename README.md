## Run Locally

Clone this repository and run a local web server:

    python -m http.server 8000

Open http://localhost:8000.

The personal profile photograph is excluded from this repository. Local previews will not display the production portrait unless the image is provided separately.

## Deployment

Hosted on an Ubuntu VPS using Nginx, with a custom domain and HTTPS provided by Let's Encrypt.
